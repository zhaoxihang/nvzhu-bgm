# 女主BGM

一个本地音效按键板。屏幕上是一排彩色按钮，点一下就播放你自己导入的音频。适合当作个人提示音、口头禅或者短音效的快捷键。

本仓库**不包含任何音乐或音效文件**。请只导入你有权使用的音频。

## 功能

- 默认 6 个空按钮，可以继续添加，也可以删除
- 点按播放，再点一次停止；点另一个按钮会换播
- 主界面长按拖动调整顺序；设置里也可以拖动排序
- 每行 2 个、3 个或 4 个
- 按钮大小：小、中、大
- 每个按钮可以单独设置图标、标签、音频、起始秒数和结束秒数
- 音频通过系统文件选择器读取，权限会保留到下次打开
- 结束时间留空则播放到音频结尾
- 不需要网络权限，没有广告

## 环境

- Android Studio（带 Android SDK 34）
- JDK 17（Android Studio 自带的 JDK 即可）
- 最低系统：Android 7.0（minSdk 24）
- 目标系统：Android 14（targetSdk 34）

## 构建

用 Android Studio 打开本目录，等 Gradle 同步完成，然后运行 `app`。

命令行：

```bash
./gradlew assembleDebug
```

调试包在 `app/build/outputs/apk/debug/app-debug.apk`。签名使用本机的 debug 密钥。

## 使用

1. 安装并打开应用。
2. 点右上角齿轮。
3. 给按钮填写名称，点「选择音频」，从手机里选一个你自己的音频文件。
4. 可选：设置起始时间、结束时间，或选一张图标。
5. 点「预览」试听，再点「保存」。
6. 回到主界面点按钮即可播放。

没有绑定音频的按钮会提示先去设置里选择。

## 关于音频

这个仓库和安装包里都没有内置音乐。应用不会下载音频。

请使用你合法获得的文件，例如你自己录制的声音、你拥有版权的作品，或者明确允许你使用的素材。不要把别人的歌曲、短剧或有声内容拆出来放进公开的安装包或仓库。
